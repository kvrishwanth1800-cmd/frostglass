# Contributor Covenant Code of Conduct

## Our pledge

We pledge to make participation in this project a harassment-free experience for everyone.

## Our standards

Examples of positive behavior include using welcoming language, respecting differing viewpoints, accepting constructive feedback, and focusing on what is best for the community.

Examples of unacceptable behavior include harassment, intimidation, discriminatory language, publishing private information, and other conduct that could reasonably be considered inappropriate in a professional setting.

## Enforcement

Report unacceptable behavior to `kvrishwanth1800@gmail.com`. Project maintainers will review and respond to reports fairly and promptly.

This Code of Conduct is adapted from the Contributor Covenant, version 2.1.
